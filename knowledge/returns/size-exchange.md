# Size exchange

Applies when a customer wants another size of an item they received.

## Check the stock first

Look up the variant of the wanted size before promising anything. If it is out of stock, offer a refund or the closest size, and say so plainly.

## Do not wait for the return

Ship the new size as soon as the carrier scans the return parcel, not when it reaches the warehouse. The exchange is free of charge once per order; a second exchange on the same order is at the customer's cost.

## If the price differs

Charge or refund the difference only above 5.00 in the order's currency. Below that, the exchange is even.
