# Damaged product returned

Applies when a customer sends back an item that arrives damaged at the warehouse.

## Check the item on receipt

Photograph the item and its parcel before anything else. Note the order number on form R-12.

## Refund or exchange

If the damage happened in transit, refund the order line in full. Offer an exchange when the same size is in stock.
